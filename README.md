# Cress Farming &mdash; Build a Cress Combine Harvester

An interactive presentation and a printable PDF report on building a small working combine harvester for home-grown cress, with an N20 gear motor driving a scissor-action cutter bar. Colour diagrams, a shopping list, step-by-step build instructions, a safety plan &mdash; and seven upgrades.

**Live presentation:** https://brendanjameslynskey.github.io/Cress_Farming/

**PDF report:** [Cress_Farming.pdf](Cress_Farming.pdf)

## What's inside

- **The pitch** &mdash; cost, time, safety and what gets learned, written for a parent who isn't an engineer
- **How a real combine works** &mdash; reel, cutter bar, feeder, threshing, grain tank, and which ones the cress combine keeps
- **The design** &mdash; side and top views with dimensions; why a crank-driven scissor knife beats a spinning blade
- **The numbers** &mdash; cuts per second, distance per cut, the "move less than half a tooth per cut" rule, reel speed ratio
- **Interactive:** cutter-bar simulator &mdash; motor RPM, push speed and knife fit versus clean cut or flattened stems
- **Shopping list, tools and who does what** (grown-up jobs marked)
- **Growing the cress** &mdash; a day-by-day timeline
- **Cutting templates** for every part
- **Six build stages** &mdash; rails and chassis, the cutter-bar sandwich, motor/crank/pitman arm, header and ground-driven reel, wiring (fuse &rarr; switch &rarr; hold-to-run button), ramp, tank and first harvest
- **Troubleshooting** table
- **Upgrades:** adjustable cutting height, PWM speed dial, self-driving with a 15 RPM N20, automatic end-of-row stop, wider header, 3D-printed cutter bar, conveyor-belt feeder
- **Safety plan**, rules card, pre-run checklist and jargon buster

## Rebuilding

```
python3 diagrams/make_diagrams.py
NODE_PATH=/path/to/node_modules node report/build_report.js   # needs puppeteer
```

## Audience

Written to be built by a young maker with a grown-up handling the craft knife and hot glue &mdash; and to convince that grown-up it's a good idea. No maths beyond ratios and multiplication, but plenty of real engineering.
